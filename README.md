# Expense Tracker

A personal finance application that helps users manage income, expenses, and budgets.

## Features

- Add transactions
- Track expenses
- Track income
- Budget management
- Analytics dashboard
- Interactive charts
- Responsive UI

## Tech Stack

- React.js
- Tailwind CSS
- JavaScript
- Vercel

## Installation

git clone https://github.com/Umer70237/expense-tracker/

npm install

npm run dev
